# Upstream attribution and license

This Skill adapts conceptual workflow elements from [`ZhengchaoW/paper-dissect`](https://github.com/ZhengchaoW/paper-dissect), especially its bottom-up source coverage discipline, typed semantic-node taxonomy, inquiry-tree reconstruction, and theorem/proof separation.

The Research-Agent adaptation changes the canonical representation and execution model: it uses repository-native Markdown files and nested folders under the project's canonical `Background/` location rather than Python-authored semantic maps, JSON graphs, or an HTML reader.
